# 공유 저장소 작업 경로

운영자가 확인한 공유 매뉴얼 저장소나 별도 작업 worktree를 설정의 `shared_roots`에 절대 경로로 등록할 수 있습니다. 기본값은 빈 목록이며 기존 팀 루트 제한을 유지합니다.

```json
{"shared_roots":["/srv/example/shared-manual-worktree"]}
```

`create`는 팀 루트 또는 명시한 공유 루트의 하위 경로만 허용합니다. 실제 경로로 resolve한 뒤 검사하므로 symlink나 `..`로 범위 밖에 나가면 거절합니다. 모든 팀은 이 공유 목록을 사용하므로 제품별로 제한해야 하는 경로는 공유 목록에 넣지 않습니다. 저장소 전체의 상위 디렉터리를 넓게 허용하지 말고 작업별 루트를 등록합니다.

팀 이름·역할·Git HEAD 고정·동일 root 구현 소유권 제한과 완료·독립 리뷰 검사는 그대로 적용합니다. 경로 등록은 원격 fetch·문서 쓰기·서버 중단·사내 push·PR·merge 권한을 추가하지 않습니다. 운영자는 최신 원격 기준과 기존 dirty 상태를 먼저 확인하고 작업별 branch/worktree를 준비해야 합니다.

공유 매뉴얼 빌드는 제품의 기존 스크립트와 지침을 따릅니다. 이 설정은 Antora의 linked worktree 지원이나 원격 네트워크를 보증하지 않으며, 빌드·실제 페이지·링크 검증은 별도 실행합니다.
