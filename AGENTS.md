# Contributor contract

- Run `python3 -m unittest discover -s tests -v` and `python3 scripts/check_public.py` for affected code before publishing.
- Keep task state, credentials, account addresses, organization identifiers, local paths, transcripts, product instructions and real quotas outside this repository. Examples use fictitious identities and paths only.
- Treat Herdr admission, agent readiness, task receipt, verification and independent review as separate facts. A timeout is an uncertain outcome, never permission to repeat a mutation.
- Before Herdr control, load `herdr --skill` and require a genuine `HERDR_ENV=1` managed pane. Never synthesize that environment to control a user's session.
- The installed CLI is the syntax authority. Test adapters with fake processes, then disclose the real runtime boundary still unverified.
- Read `docs/operations.md` for account changes, handoff, shared manuals and PR gates. Keep implementation and review independent; bind reviews to the current head.
- Preserve user changes and person-only commit authorship.
