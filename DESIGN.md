# Team operations interface

The board is an operational workspace. Its reference is Notion's property-oriented board organization: a card exposes useful attributes and opens a focused detail view. It groups by responsibility for the next action: agent waiting, observed execution, operator decision, and completed or organized records. Operational errors remain with the responsible agent; they do not create an operator choice.

Cards show a short title and explanation, the responsible person, current activity and current-design session. Historical sessions remain in details. The normal UI uses proportional host typography; monospace is reserved for source and identifiers. Account usage is secondary and collapsible.

The document reader starts with purpose, changes, checks, impact and decision meaning. Full Markdown, contract and exact source are separate views. The reading baseline is 16px text, 24px line height and a 700px measure, informed by the inspected Obsidian reading stylesheet. Native TextView does not support CSS; this is a native reading layout, not a claim of identical browser typography. Inline code and code fences retain Markdown syntax; source is never rewritten to improve a preview.

Explicit controls organize, archive and restore a board card. A completed board organization has a distinct label from actual work completion. New design or question content makes an organized card visible again. Native dialogs close by button, Escape and outside press; closing does not submit.
